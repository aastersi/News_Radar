# Security

## Secrets

Секреты хранятся только в переменных окружения (`.env` рядом с `compose.yaml`) или в хранилище секретов среды запуска. Файлы `.env`, `sources.yaml`, базы и журналы не коммитятся и не попадают в Docker-образ (`.gitignore`, `.dockerignore`).

Секреты Radar:

- `RADAR_TELEGRAM_BOT_TOKEN` — отдельный бот только этого проекта;
- `RADAR_X_BEARER_TOKEN` — app-only токен X для чтения;
- `RADAR_LLM_API_KEY` — ключ LLM-провайдера.

Секретов публикации нет. Никогда не добавляйте в Radar:

- seed phrase;
- приватный ключ кошелька;
- пользовательские cookies X;
- сохранённую браузерную сессию;
- секреты других проектов, включая Brain.

Если токен попал в чат, журнал или коммит, отзовите его у провайдера (BotFather `/revoke`, console.x.com, кабинет LLM) и обновите `.env`.

## Publication safety

Публикация в Quote Memorial и X не реализована. Защита в несколько слоёв:

1. В composition root зарегистрированы только `DisabledQuotePublisher` и `DisabledXPublisher`; их `publish` всегда бросает `PublishingDisabled`.
2. `RADAR_QMEMO_PUBLISHING_ENABLED=true` или `RADAR_X_PUBLISHING_ENABLED=true` останавливает `qmemo-radar run` с ошибкой конфигурации (fail-closed).
3. Outbox worker отсутствует: одобренный пакет только хранится со статусом `APPROVED`.
4. Тест проверяет, что единственный HTTP POST в коде — запрос к LLM `/chat/completions`, а X-клиент выполняет только GET.
5. Все тесты блокируют сетевые соединения, кроме loopback.

Реальная публикация включается только при одновременном выполнении условий:

1. Реальный адаптер явно зарегистрирован в `bootstrap.py`.
2. Соответствующий флаг публикации равен `true`.
3. Startup self-check подтвердил конфигурацию и доступность API.

## Budget

- Платные функции (`RADAR_PAID_SOURCES_ENABLED`, `RADAR_X_PAID_SEARCH_ENABLED`, `RADAR_PAID_LLM_ENABLED`) по умолчанию выключены; выключенная функция не создаёт HTTP-клиент и не требует ключа.
- Каждый платный адаптер обязан получить `BudgetGuard` в конструкторе. Резерв стоимости записывается в `cost_ledger` внутри `BEGIN IMMEDIATE` до запроса; при неизвестной цене или достигнутом месячном пределе запрос не отправляется.
- `RADAR_COST_HARD_LIMIT_USD_MONTHLY` нельзя поднять выше 10.

## X

X — опциональный платный источник. Используется только официальный X API v2 на чтение: `GET /2/tweets/search/recent` и `GET /2/tweets/{id}`. Scraping, cookies и браузерные сессии запрещены. Ручная ссылка принимается только в виде `https://x.com/<handle>/status/<id>`; сам URL никогда не загружается — из него берётся числовой ID для API.

## LLM и недоверенный текст

- Текст публикаций, данные автора, прошлый черновик и инструкция пользователя передаются модели только как JSON-блоки данных. Символ `<` экранируется, поэтому данные не могут закрыть свой блок.
- Системные промпты — константы, которые не зависят от входных данных; они запрещают выполнять инструкции из данных и штрафуют попытки манипуляции.
- Ответ модели проверяется Pydantic: набор `event_id` должен совпасть с входным ровно по одному разу, итоговый балл пересчитывает код.
- Цитата обязана дословно совпадать с источником после нормализации пробелов и кавычек; имя говорящего должно быть написано в самой публикации.
- Спорные факты получают `NEEDS_REVIEW`, пакет создаётся только после `VERIFIED`.

## Telegram

- Каждое сообщение, команда и callback сначала проверяет `from_user.id == RADAR_ALLOWED_TELEGRAM_ID`. Остальным отвечается только «Нет доступа» с их собственным ID, без состояния системы.
- Весь внешний текст экранируется для HTML.
- Callback-data содержит полный 32-символьный идентификатор и не длиннее 64 байт.

## Logs

JSON-журналы содержат `run_id`, `event_id`, модуль, операцию, результат и код ошибки. В них не пишутся токены и ключи (дополнительно вырезаются форматтером), полный текст публикаций, payload X, промпты и ответы модели. Библиотеки, которые на низких уровнях пишут параметры SQL и URL, ограничены уровнем WARNING.

## Reporting

Не создавайте публичный issue с секретами или персональными данными. Передавайте уязвимость владельцу репозитория приватным каналом.
